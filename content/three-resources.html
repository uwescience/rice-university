Answer these before choosing a service; the cost follows from the answers.

You already think this way on the cluster: scratch versus project storage, node types, the interconnect. In the cloud each of the three is metered separately, so each answer has a price. Point at the arrow leaving the region: network is the one researchers forget. Moving data between storage and compute in the same region is usually free; moving it out of the cloud is billed per gigabyte (about 9 cents, which the costs slide comes back to). Thinking like an engineer means answering these before choosing a service.
