# Key message
A shared hub replaces setup day

## Talking points
- Anyone who has run a workshop has lost the first hour to installs and package conflicts
- With a hub, a browser is enough, so students on Chromebooks or old laptops take part on equal terms
- Instructors hand out, collect and grade notebooks in one place, and can offer GPUs most students do not own
- For research IT, that means fewer first-week tickets and no lab image to rebuild each semester

## Slot: left
### Laptop setup
- First hour lost to installs
- Different versions on every machine
- Needs a capable personal laptop
- Every student downloads the data

## Slot: right
### Shared hub
- Teaching starts in minute one
- One identical environment for all
- Any browser, any device
- Data waits on the server
