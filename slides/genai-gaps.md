# Key message
Generative AI fills the gaps provider docs leave

## Talking points
- Provider docs describe each service, rarely the path between three of them
- An assistant can draft the CLI steps, the IAM policy and the config file
- It will be confidently wrong sometimes: the error message is the next prompt
- Research IT's role shifts from writing the steps to reviewing them

## Slot: support
Treat its answer as a draft: run it, read the errors, ask again.
