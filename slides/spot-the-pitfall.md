# Key message
Spot the pitfall

## Slot: time
3 min

## Slot: steps
1. Listen to three short scenarios
2. Name the pitfall in each one
3. Suggest one guardrail that prevents it

## Slot: deliverable
One guardrail per scenario, shared aloud

## Notes
Draft scenarios to read aloud (planner-invented; edit freely):
1. A GPU machine launched for a Friday demo is still running on Monday.
2. A student pushes a notebook containing an access key to a public repository; instances appear in a region the lab never uses.
3. A lab keeps 40 TB of raw images, read twice a year, in standard object storage, then downloads all of it to campus.
