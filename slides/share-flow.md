# Key message
From one lab's project to everyone's resource

## Talking points
- Most cloud projects end with artifacts nobody else can find
- GitHub for code and training modules, Hugging Face for models and datasets
- A shared catalog across institutions turns those into a marketplace
- Open outputs are also the best exit plan: the work outlives the award

## Slot: nodes
- Build: Work in a cloud project
- Publish: GitHub code; Hugging Face models, data
- Discover: A shared catalog across institutions
- Reuse: Another lab runs it unchanged

## Slot: caption
Open science is the exit plan that keeps paying off.
