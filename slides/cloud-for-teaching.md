# Key message
Teaching modules that outlive a single course

## Talking points
- Sample datasets live in one place instead of on 60 laptops
- Educators at different institutions can build and edit the same materials
- A module that runs on a shared hub runs the same way for the next instructor
- Updating it once updates it for every course that adopts it

## Slot: nodes
- Share: Sample datasets in one place
- Co-develop: Educators edit the same materials
- Reuse: Runs unchanged at another institution
- Update: Revise and republish each term

## Slot: caption
One shared hub and repository serve every course that adopts the module.
